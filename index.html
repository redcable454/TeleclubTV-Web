PREGUNTAS FRECUENTES

Antes de comenzar

¿En qué dispositivos puedo instalar la aplicación?

La aplicación está destinada a dispositivos Android compatibles, incluidos celulares y TV Box. La compatibilidad puede variar según el modelo y la versión de Android.

¿Cómo recibo mis datos de acceso?

Solicita el servicio desde el sistema de contratación. Los datos de acceso se entregan cuando se activa tu cuenta.

¿La prueba gratis dura dos horas?

La opción de demostración está configurada para una duración de dos horas cuando se encuentra habilitada. La solicitud y activación se gestionan desde el sistema de Teleclub TV.

¿Dónde consulto la programación?

Entra en la sección Guía TV de esta web para consultar la información EPG disponible.

¿Qué necesito para usar el servicio?

Un dispositivo compatible, conexión estable a internet y una cuenta activa de Teleclub TV.
